# Licence decision (adopted 2026-11-01)

| Part | Licence | File |
|---|---|---|
| Code: `skills/*/scripts/`, `*.py`, `*.R`, `*.sh` | MIT | `LICENSE` |
| Text: `SKILL.md`, `references/`, `templates/*.md`, `docs/`, README | CC BY 4.0 | `LICENSE-CC-BY-4.0` |
| Simulated example data and output figures | CC BY 4.0 | — |

Why:
- MIT is the norm for template code.
- CC BY allows teaching reuse, translation and adaptation with attribution.
- NC or ND terms were rejected because they hinder course use and adaptation.
