# Figure review rubric

## Step 1 – 1-second test
Show the figure for ~1 s (or glance at thumbnail). Write what you noticed first. If it isn't the intended message, hierarchy/contrast is wrong.

## Step 2 – Reverse feedback
Before reading the caption, the reviewer explains in their own words what the figure shows. The author compares to their intended message; gaps = fixes. (Concept from Jambor's "figure hero" checklist.)

## Step 3 – Score (0 = absent, 1 = poor, 2 = adequate, 3 = good, 4 = exemplary)
| # | Criterion | 4 looks like |
|---|---|---|
| 1 | Message | single clear take-home, title/caption states it |
| 2 | Chart choice | chart matches data structure & comparison |
| 3 | Statistical honesty | raw data visible, n and SD/SE/CI defined, honest axes |
| 4 | Typography | one sans family, ≥ min pt at final size, ≤3 sizes, units |
| 5 | Multi-panel layout | aligned grid, labels consistent (journal case), logical order, shared axes/legends |
| 6 | Colour | ≤5 hues, consistent meaning, CVD-safe, no coloured text |
| 7 | Cognitive load | no chartjunk, direct labels, whitespace groups |
| 8 | Technical specs | correct width mm, dpi, fonts embedded, file format |
Total /32. Grade bands: ≥28 publication-ready; 20–27 minor revision; 12–19 major revision; <12 redesign.

### Hard gate (cannot be offset by a high total)
- Publication-ready requires BOTH: (a) Total ≥ 28, AND (b) Statistical honesty (criterion #3) ≥ 1.
- If Statistical honesty = 0 — including absent data provenance (e.g., n/SD/SE/CI undefined) or any major misleading presentation (e.g., dishonest axes, cherry-picking) — the figure CANNOT be marked publication-ready regardless of total score.

## Output format
1. 1-second impression · 2. Scores table with one-line evidence each · 3. Top 3 fixes (most impact first) · 4. One thing done well.
Use `templates/rubric_form.md` for grading; weights may be changed for courses (e.g., GA: replace #3 with "Visual flow").
