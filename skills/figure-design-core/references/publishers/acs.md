# American Chemical Society (ACS): figure specifications

Last checked: 2026-11-01. Status markers: ✅ verified at the cited source; ⚠️ unverified or secondary source, so check before use.

## Publisher base rules
| Item | Rule | Source / status |
|---|---|---|
| Font | Helvetica or Arial work well | ✅ [ACS] |
| Font size | ≥ 4.5 pt at final size | ✅ [ACS] |
| Column widths | Single ≤ 240 pt (3.33 in); double 300–504 pt (4.167–7 in) | ✅ [ACS] |
| Max figure dimensions | Depth ≤ 660 pt (9.167 in) including caption | ✅ [ACS] |
| File formats | Embedded in manuscript at first mention | ✅ [ACS] |
| Resolution | B/W line art 1200; greyscale 600; colour 300 dpi | ✅ [ACS] |
| Colour mode | Colour free; don't submit colour for B/W figures | ✅ [ACS] |
| Line weights | ≥ 0.5 pt | ✅ [ACS] |
| TOC graphic | 3.25 × 1.75 in; sans-serif 8 pt (≥ 6 pt); TIFF 300 dpi colour / 1200 B/W, or EPS RGB | ✅ [TOC] |

## Journal exceptions
None verified; rules come from per-journal Author Guidelines that share Appendix 2.
