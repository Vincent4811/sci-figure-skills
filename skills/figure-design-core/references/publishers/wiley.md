# Wiley: figure specifications

Last checked: 2026-11-01. Status markers: ✅ verified at the cited source; ⚠️ unverified or secondary source, so check before use.

## Publisher base rules
| Item | Rule | Source / status |
|---|---|---|
| Font | Not prescribed centrally | ⚠️ check journal |
| Font size | Not prescribed; "larger fonts make for easier reading" | ✅ [W] |
| Column widths | Create figures 80–180 mm wide; at least 80 mm canvas or 1800 px wide | ✅ [W] |
| Max figure dimensions | Not stated centrally | ⚠️ |
| File formats | Line art: EPS or PDF preferred; images: PNG or TIFF; any standard type (PDF if in doubt) at review; each file < 10 MB | ✅ [W] |
| Resolution | Line art 600 dpi; images 300 dpi (300–600 dpi overall) | ✅ [W] |
| Colour mode | Not stated centrally | ⚠️ |
| Panel label style | Not prescribed | ⚠️ journal-specific |
| Line weights | Not stated | ⚠️ |
| Other | Name file by figure number only; remove extra white space | ✅ [W] |

## Journal exceptions
None verified yet. Many Wiley journals (and former Hindawi titles, now Wiley) have their own author guidelines; check the journal page.
