# AAAS (Science family): figure specifications

Last checked: 2026-11-01. Status markers: ✅ verified at the cited source; ⚠️ unverified or secondary source, so check before use.

## Publisher base rules (Science)
| Item | Rule | Source / status |
|---|---|---|
| Font | Sans-serif, Helvetica preferred (prep guide: Arial or Helvetica) | ✅ [SCI] |
| Font size | ~7 pt, not < 5 pt; prep guide: labels 6–9 pt | ✅ [SCI]; ⚠️ [GUIDE] |
| Column widths | 5.7 cm (1 col), 12.1 cm (2 col), 18.4 cm (3 col) | ✅ [SCI][REV] |
| File formats | Vector preferred (Illustrator); no PowerPoint; revised: separate files | ✅ [SCI][REV] |
| Resolution | 300 dpi initial; revised ≥ 300 dpi at final size, higher if possible; no upsampling | ✅ [REV] |
| Panel label style | Uppercase A, B, C, 10 pt bold, upper left | ✅ [SCI] |
| Other | Avoid coloured type; bold type on colour; leading zeros; sentence-case labels | ✅ [SCI] |

## Journal exceptions
### Science Advances
| Item | Differs how | Source / status |
|---|---|---|
| Widths | 9 cm (1 col), 18.4 cm (2 col); in-between ≤ 14.4 cm | ✅ [SA] |
| Max depth | 22.75 cm; 19.9 cm recommended to fit legend | ✅ [SA] |
| Fonts | Labels 8 pt Myriad (min 6 pt); panel letters 9 pt Myriad bold caps | ✅ [SA] |
| Lines | ≥ 0.28 pt | ✅ [SA] |

### Science Translational Medicine
| Item | Differs how | Source / status |
|---|---|---|
| Widths | 1 col 3.5 in, 1.5 col 5.0 in, 2 col 7.3 in | ✅ [STM] |
