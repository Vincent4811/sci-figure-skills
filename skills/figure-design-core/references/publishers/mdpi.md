# MDPI: figure specifications

Last checked: 2026-11-01. Status markers: ✅ verified at the cited source; ⚠️ unverified or secondary source, so check before use.

## Publisher base rules
| Item | Rule | Source / status |
|---|---|---|
| Font | Common standard fonts; avoid Symbol/Wingdings; all fonts embedded | ✅ [MD] |
| Font size | Not stated | ⚠️ |
| Column widths | Not stated; production team places figures | ⚠️ |
| File formats | Any common format (tif, jpg, png...); published as TIFF | ✅ [MD] |
| Resolution | ≥ 600 dpi recommended | ✅ [MD] |
| Colour mode | Not stated | ⚠️ |
| Panel label style | a, b, c (or A, B) rather than left/right | ✅ [MD] |
| Other | No "[XX]" references, watermarks or QR codes in images; lock aspect ratio; use × 10ⁿ, not e-notation; leading zero; captions below | ✅ [MD] |
| Graphical abstract | PNG/JPEG/TIFF, ≥ 560 × 1100 px (h × w) | ✅ [MD] |
