# Cambridge University Press: figure specifications

Last checked: 2026-11-01. Status markers: ✅ verified at the cited source; ⚠️ unverified or secondary source, so check before use.

## Publisher base rules
| Item | Rule | Source / status |
|---|---|---|
| Font | Clear, legible typefaces; match text style (e.g. italics) | ✅ [CUP] |
| Font size | "Large enough to be easily read"; no number given | ✅ [CUP] |
| Column widths | Not stated centrally | ⚠️ journal-specific |
| File formats | TIFF recommended (compressed, LZW); EPS for line/combination; PDF with embedded fonts | ✅ [CUP] |
| Resolution | Halftone 300 dpi; line art 1000 dpi (1200 if very fine lines); combination ≥ 600 dpi | ✅ [CUP] |
| Colour mode | Halftones colour (CMYK) or B/W | ✅ [CUP] |
| Other | Colour-blind-safe palettes; captions in manuscript text, not image | ✅ [CUP] |
