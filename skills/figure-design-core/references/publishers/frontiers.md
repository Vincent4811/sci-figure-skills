# Frontiers: figure specifications

Last checked: 2026-11-01. Status markers: ✅ verified at the cited source; ⚠️ unverified or secondary source, so check before use.

## Publisher base rules
| Item | Rule | Source / status |
|---|---|---|
| Font | Not prescribed | ⚠️ |
| Font size | Smallest text ≥ 8 pt at actual size | ✅ [FR] |
| Column widths | 85 mm (one column) or 180 mm (two columns) | ✅ [FR] |
| Max figure dimensions | Not longer than one page | ✅ [FR] |
| File formats | TIF/TIFF, JPEG, EPS (EPS upon acceptance); figures in the PDF for LaTeX | ✅ [FR] |
| Resolution | 300 dpi at final size | ✅ [FR] |
| Colour mode | RGB | ✅ [FR] |
| Line weights | ≥ 2 pt | ✅ [FR] |

## Journal exceptions
None found; Frontiers uses one central guideline.
