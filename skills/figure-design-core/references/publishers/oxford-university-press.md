# Oxford University Press (Oxford Academic): figure specifications

Last checked: 2026-11-01. Status markers: ✅ verified at the cited source; ⚠️ unverified or secondary source, so check before use.

OUP has no single binding journal figure spec: its general page points to short guidelines and says to follow each journal's own instructions. The base below is the common pattern across OUP journal pages, not a central rule.

## Publisher base rules
| Item | Rule | Source / status |
|---|---|---|
| Font | Not prescribed centrally | ⚠️ |
| Font size | Not prescribed centrally | ⚠️ |
| Column widths | Journal-specific | ⚠️ |
| File formats | EPS or TIFF common; many journals also accept JPEG, PDF, BMP | ⚠️ [OUP] + journal pages |
| Resolution | Typical: colour/greyscale 300–600 dpi; line art ≥ 600–1200 dpi | ⚠️ pattern from [JPR][JAS] |
| Colour mode | Journal-specific (RGB online is common) | ⚠️ |

## Journal exceptions
### Journal of Plankton Research
| Item | Differs how | Source / status |
|---|---|---|
| Widths | 80 mm single, 164 mm double; max 220 × 164 mm including legend | ✅ [JPR] |
| Resolution | Colour/greyscale 300–600 dpi; line art ≥ 1200 dpi | ✅ [JPR] |
| Formats / colour | TIFF, BMP, JPEG, PDF, PS/EPS; colour in RGB | ✅ [JPR] |

### Journal of Animal Science
| Item | Differs how | Source / status |
|---|---|---|
| Widths | 8.9 / 14 / 19 cm | ✅ [JAS] |
| Font / size | Helvetica and Times New Roman only; ≥ 8 pt | ✅ [JAS] |
| Lines | ≥ 1 pt | ✅ [JAS] |
| Resolution | 300 dpi colour/grey; 600 dpi line art | ✅ [JAS] |
| Colour | CMYK for colour in print | ✅ [JAS] |
