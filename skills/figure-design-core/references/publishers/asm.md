# American Society for Microbiology (ASM): figure specifications

Last checked: 2026-11-01. Status markers: ✅ verified at the cited source; ⚠️ unverified or secondary source, so check before use.

All rows come from 2010–2011 ASM Instructions to Authors and a search summary; current ASM pages were not read in full. Check before use.

## Publisher base rules
| Item | Rule | Source / status |
|---|---|---|
| Font | Arial, Helvetica, Times Roman, European PI, Mathematical PI, Symbol; otherwise outline fonts | ⚠️ [ASM] |
| Column widths | 1 col ≤ 8.4 cm (3 5/16 in); 2 col 10.8–17.4 cm | ⚠️ [ASM] |
| Max figure dimensions | Height ≤ 23 cm | ⚠️ [ASM] |
| File formats | TIFF or EPS, editable; multipanel in one file | ⚠️ [ASM] |
| Resolution | Grey/colour 300; combination 600; line art 1200 dpi | ⚠️ [ASM] |
| Colour mode | RGB preferred; CMYK accepted | ⚠️ [ASM] |

## Journal exceptions
None verified (JCM, JVI, mBio and others share the ASM pattern).
