# PLOS: figure specifications

Last checked: 2026-11-01 (PLOS ONE figures page fetched in full). ✅ verified; ⚠️ check before use.

## Publisher base rules
| Item | Rule | Source / status |
|---|---|---|
| Font | Arial, Times, or Symbol only | ✅ [PONE] |
| Font size | 8–12 pt | ✅ [PONE] |
| Panel label style | Not prescribed in the figure file. Legends describe each panel by a lettered label, "(A) or (a)". Text cites "Fig 1A". Uppercase is the common practice. | ✅ [PONE]; ⚠️ "uppercase common" is an observation |
| Column widths | Width 789–2,250 px at 300 dpi (6.68–19.05 cm). To align with the text column, ≤ 13.2 cm (5.2 in). | ✅ [PONE] |
| Max figure dimensions | Height up to 2,625 px at 300 dpi (22.23 cm), excluding the caption | ✅ [PONE] |
| File formats | TIFF (LZW compression required) or EPS only; < 10 MB; flattened, no alpha channel, one page | ✅ [PONE] |
| Resolution | 300–600 dpi | ✅ [PONE] |
| Colour mode | RGB (8 bit per channel) or greyscale | ✅ [PONE] |
| Text in EPS | Embed fonts or convert to outlines (PLOS allows outlines, unlike Nature) | ✅ [PONE] |
| Other | No captions, titles, figure numbers or author names inside the image; 2 pt white border recommended; name files Fig1.tif and so on; check with the NAAS tool; image-manipulation and blot/gel rules apply | ✅ [PONE] |
| Formatting at submission | PLOS ONE waives formatting until provisional acceptance | ✅ [PONE] |

## Journal exceptions
- **PLOS Biology, PLOS Pathogens:** same core specification (dimensions, 300–600 dpi, < 10 MB, Arial/Times/Symbol 8–12 pt). No differences found. ✅ [PBIO]
- **PLOS Computational Biology:** assumed to share the PLOS specification. ⚠️ Not verified separately; check before use.
