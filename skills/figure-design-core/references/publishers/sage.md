# SAGE: figure specifications

Last checked: 2026-11-01. Status markers: ✅ verified at the cited source; ⚠️ unverified or secondary source, so check before use.

## Publisher base rules
| Item | Rule | Source / status |
|---|---|---|
| Font | Usually sans-serif; not too much variation in size and type | ⚠️ [SS] support article |
| Font size | Avoid type below 6 pt at final size | ⚠️ [S13] 2013 guide |
| Column widths | Not stated centrally; match or exceed journal dimensions | ⚠️ [SS] |
| Max figure dimensions | Not stated centrally | ⚠️ |
| File formats | Line art as vector EPS; TIFF/JPEG for pictures; (2013 guide: TIFF, EPS, JPEG, press-ready PDF) | ✅ [SP] EPS; ⚠️ [SS][S13] rest |
| Resolution | ≥ 300 dpi; line art ≥ 800 dpi (support article) or 1200 ppi (2013 guide) | ✅ [SP] 300; ⚠️ line art conflict |
| Colour mode | Colour often online only, B/W in print unless arranged; make figures readable in greyscale | ⚠️ [SS] |
| Other | Submit figures separately, not embedded in Word | ✅ [SP] |

## Journal exceptions
### Journal of Histochemistry & Cytochemistry (JHC)
| Item | Differs how | Source / status |
|---|---|---|
| Font | Times, Times New Roman, Arial, Frutiger, Sabon only | ✅ [JHC] |
| Max size | 6.75 × 8.75 in (17.1 × 22.1 cm), portrait | ✅ [JHC] |
| Resolution | Halftone 300 dpi; line art and combination 800 dpi | ✅ [JHC] |
| Colour | Submit RGB | ✅ [JHC] |
