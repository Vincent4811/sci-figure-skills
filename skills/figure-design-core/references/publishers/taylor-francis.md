# Taylor & Francis: figure specifications

Last checked: 2026-11-01. Status markers: ✅ verified at the cited source; ⚠️ unverified or secondary source, so check before use.

## Publisher base rules
| Item | Rule | Source / status |
|---|---|---|
| Font | Standard fonts, embedded: Helvetica, Arial, Times New Roman, Symbol | ✅ [TF] |
| Font size | Consistent; no minimum stated | ✅ [TF] |
| Column widths | Not stated centrally; supply at intended publication size | ⚠️ journal-specific |
| Max figure dimensions | Not stated centrally | ⚠️ |
| File formats | Peer review: JPEG, TIFF, DOC/DOCX (older guide also EPS, PS). EPS/PS recommended for line art and labelled combinations. PDF is converted (older guide: do not supply PDF) | ✅ [TF]; ⚠️ older PDF [TF17] |
| Resolution | Colour photo 300 dpi; greyscale photo 600 dpi; line art 1200 dpi; combination 600 dpi | ✅ [TF] |
| Colour mode | Not stated in author guide; T&F production spec: online RGB, print CMYK | ⚠️ [JATS] production doc |
| Line weights | ≥ 0.3 pt | ✅ [TF] |
| Other | No layers or transparency; figures and captions in separate files from text | ✅ [TF] |

## Journal exceptions
None verified yet; follow each journal's Instructions for Authors on tandfonline.com.
