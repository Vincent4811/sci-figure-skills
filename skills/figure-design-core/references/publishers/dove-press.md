# Dove Medical Press (Taylor & Francis group): figure specifications

Last checked: 2026-11-01. Status markers: ✅ verified at the cited source; ⚠️ unverified or secondary source, so check before use.

## Publisher base rules
| Item | Rule | Source / status |
|---|---|---|
| Font | Arial and Symbol, embedded | ✅ [DV] |
| Font size | Consistent; no effects (outline, shadow) | ✅ [DV] |
| Column widths | Not stated | ⚠️ |
| Max figure dimensions | File ≤ 50 MB | ✅ [DV] |
| File formats | JPEG, BMP, PNG, GIF, TIFF; separate from manuscript | ✅ [DV] |
| Resolution | Colour photo 300; greyscale 600; line art 1200; combination 600 dpi | ✅ [DV] |
| Colour mode | RGB | ✅ [DV] |
| Panel label style | A, B, C, D | ✅ [DV] |
| Line weights | ≥ 0.3 pt | ✅ [DV] |
| Other | No layers or transparency; name "[manuscript ID] Figure [n]" | ✅ [DV] |

None found; Dove uses one central guideline.
