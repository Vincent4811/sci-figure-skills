# 第 3 單元：圖像摘要（GA）與資訊圖表

## 學習目標
- 能依照「訊息 → 版面與動線 → 圖示 → 箭頭 → 文字 → 顏色」的流程完成一張 GA。
- 能區分圖像摘要與直式資訊圖表的規格。

## 重點
- **四種版面骨架**：
  - 線性：適合呈現流程
  - 循環：適合呈現回饋或循環
  - 平行：適合對照組與處理組的比較
  - 巢狀：適合跨尺度的呈現，例如食品 → 細胞 → 分子
- **圖示**：
  - 風格要一致。
  - 常用來源：Bioicons、Servier SMART、Reactome、PhyloPic、Health Icons。
  - 使用前要確認授權，並依規定標註出處。
- **文字與顏色**：
  - 文字越少越好。
  - 顏色用 2–3 色，再加上中性色。
  - 文字對比度至少 4.5:1，可用 WebAIM 檢查。
- **Jambor & Bornhäuser（2024）的十項建議**：課程中以轉述方式說明，詳見技能檔。

## 工具
- PowerPoint：先設定投影片尺寸。
- Inkscape：適合向量繪圖，並可設定 mm 尺寸。
- BioRender：用於發表時需要付費授權。
- Canva：使用前要注意素材的授權。

## 延伸：資訊圖表的三大類型（整理自 Figma 資源庫）
來源：Figma Resource Library〈46 infographic examples for data-driven storytelling〉，https://www.figma.com/resource-library/infographic-examples/ （2026-11-01 查閱）。以下為改寫摘要，未轉載任何圖片。

1. **統計型**：用圖表整理數據與調查結果。
   - 同一張可以混用地圖、折線圖、長條圖、環圈圖，但每張圖要回答不同的問題。
   - 放大的數字最吸睛，旁邊要標明單位與資料來源。
2. **資訊型**：說明概念，常見形式如下。
   - 清單：一項搭配一個圖示
   - 時間軸：里程碑
   - 階層：金字塔、樹狀圖
   - 比較：左右對照、優缺點、文氏圖
   - 地圖：區域資料
3. **流程型**：呈現步驟或決策。
   - 可用流程圖、循環圖、決策樹或編號步驟。
   - 用箭頭與大號步驟編號引導閱讀。

**值得借用的手法**：
- 先用一個「讀圖說明」小圖教讀者怎麼看，再重複同一種小圖（就是小倍數圖加上圖例）。
- 實驗流程用編號步驟呈現，例如：採樣 → 增菌 → 塗盤 → 計數。
- 用決策樹幫讀者選擇方法，終點以醒目的顏色標示。
- 調色盤只用互補兩色（例如藍與橘）或單色系，並保留足夠的留白。

**好資訊圖表的四要素**：
1. 內容精簡、重要
2. 有完整的故事，脫離原文也看得懂
3. 風格一致
4. 尺寸符合發布平台，字體清楚、不擁擠

**科學用途的提醒**：行銷範例常見漸層、照片當底圖、混用多種字型。科普圖仍應遵守以下原則：
- 只用一種無襯線字型
- 文字對比度至少 4.5:1
- 標註資料來源
- 模擬數據要明確標示
